# Support

## Questions about the research

Open a GitHub Discussion or Issue only after the repository is public and moderated. Keep questions focused on the public materials.

## Reproduction help

Start with `docs/REPRODUCIBILITY.md` and the scripts under `scripts/`. Include your OS, Python version, and the exact command that failed. Do not attach private data.

## Security and privacy concerns

See `SECURITY.md`. Do not post secrets or private exports in issues.
