# Figures

Rendered figures are stored in `figures/rendered/`. Numbering follows first appearance in the public manuscript. Source renumbering maps are in `figures/source_data/` and `data/aggregate/renumbering/`.

| Coverage | Figures |
|---|---|
| Fully reproducible from public code and data | None; figure generation code remains private |
| Partially reproducible | Figures whose aggregate source tables are public |
| Not publicly reproducible | Figures requiring withheld text, race-label inputs, or private analytics joins |

Frozen race figures (`fig21_frozen_race_models.png`, `fig22_claimB_uncertainty.png`) are included as published visual records. They are not regenerated by the public package.
