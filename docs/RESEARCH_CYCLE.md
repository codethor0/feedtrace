# Research Cycle

1. Collect new creator-owned data in the private workspace.
2. Preserve raw inputs as immutable, date-stamped snapshots and hash them.
3. Validate counts, uniqueness, types, timestamps, and missingness.
4. Separate feed-level and analytics-level observations; record post age.
5. Recover verified full text only in the private workspace.
6. Complete human review for high-impact labels when applicable.
7. Freeze a private analysis checkpoint.
8. Run descriptive, confirmatory, and exploratory analyses separately.
9. Apply multiple-testing corrections and robustness checks.
10. Preserve contradictory evidence and conduct adversarial review.
11. Compare against the previous public release.
12. Build a new sanitized public package from an allowlist.
13. Run privacy, secret, identifier, licensing, and reproducibility audits.
14. Owner manually commits, pushes, and creates the release.
15. Never alter a historical release after publication.

Near-term priorities: human validation of race-related labels as a new result set, fixed-age snapshots, broader analytics coverage, multi-account comparisons, network-composition measurement, and dependence-aware uncertainty.
