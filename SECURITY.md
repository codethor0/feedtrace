# Security Policy

## Supported versions

Security updates apply to the latest public release of this repository.

## Reporting a vulnerability

Do not open a public issue for secrets, credentials, private data leaks, or security vulnerabilities.

Preferred reporting path:

1. Use GitHub private vulnerability reporting if enabled for this repository.
2. If private vulnerability reporting is unavailable, contact the repository owner through the GitHub account that owns the repository.

## Scope

In scope:

- Accidental inclusion of secrets, tokens, cookies, or credentials
- Accidental inclusion of private LinkedIn exports or identifiers
- Unsafe CI or dependency configuration in this repository

Out of scope:

- LinkedIn platform security issues
- Social-engineering reports that require private data uploads
